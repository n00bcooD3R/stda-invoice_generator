⚙️ Sandbox.co.in GST API Settings

This app connects to Sandbox.co.in GSP API for instant live GSTIN search, auto-filling business legal name, trade name, full address, and state code.

🔑 On Vercel, set SANDBOX_API_KEY in Environment Variables for automated production lookups.
⚡ How Option B works on Vercel:
  • Vercel serves serverless endpoint at /api/gst-lookup?gstin=...
  • Typing any 15-digit GSTIN or clicking 🔍 Fetch API calls Sandbox.co.in.
  • Client details automatically fill into Buyer fields and store locally for offline access!
